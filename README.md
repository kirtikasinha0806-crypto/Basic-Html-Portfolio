# Basic HTML Portfolio

## About the Project
This is my basic student portfolio created using HTML5 as part of my frontend development learning journey. The project demonstrates the use of basic HTML tags and concepts learned in the classroom.

## Features
- Personal information section
- Education details and academic records
- School and college links
- Links to 10th and 12th marksheets
- Certificates section
- Technical skills and hobbies
- Career objective
- Projects section
- Separate contact page with an HTML form
- Navigation links to different sections of the portfolio

## Technologies Used
- HTML5

## Project Files
- `index.html` – Main portfolio webpage
- `contact.html` – Contact form webpage
- `10th-marksheet.jpeg` – Class 10 marksheet image
- `12th-marksheet.jpeg` – Class 12 marksheet image
- `SIH-internal-certificate.jpeg` – Certificate image
- `Viveka-certificate.jpeg` – Certificate image

## HTML Concepts Used
- Headings and paragraphs
- Line breaks and horizontal lines
- Bold, italic, small and big text
- Images and hyperlinks
- Absolute and relative links
- Ordered and unordered lists
- Tables with captions, table headings and table rows
- HTML5 semantic tags such as `header`, `main`, `section`, `article` and `footer`
- Forms, labels, radio buttons, checkboxes, dropdown lists and text areas

## Learning Outcome
Through this project, I learned how to structure a webpage using HTML5, organize personal and academic information, create hyperlinks to documents and build a basic contact form.

## How to Run
1. Download or clone this repository.
2. Keep the HTML files and image files in the appropriate project folder.
3. Open `index.html` in a web browser.
